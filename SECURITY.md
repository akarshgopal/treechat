# Security

TreeChat keeps each person's API key in their own browser and sends it only to the provider they chose, so the problems that matter most are ones that could leak a key or chats: script injection through replies, cited pages, documents or imported files, and requests sent somewhere they should not go.

## Reporting a vulnerability

Please report it privately, not in a public issue: on GitHub, open the **Security** tab of this repository and choose **Report a vulnerability**. Include what an attacker could do and the steps to reproduce it.

You can expect a reply within a week. Fixes ship to [treechat.cc](https://treechat.cc/) as soon as they are ready, and the report is credited unless you prefer otherwise.
